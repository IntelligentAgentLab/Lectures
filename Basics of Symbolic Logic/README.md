# 기호논리의 기초: 명제논리에서 논리 기반 학습까지

## 강의 구성 원칙

이 강의는 논리식을 읽고 쓰는 기초에서 출발하여, 논리적 추론을 계산하고 데이터로부터 규칙을 학습하는 과정까지 다룬다. 전체 흐름은 다음과 같다.

$\text{명제논리}\rightarrow \text{SAT}\rightarrow \text{일차논리(FOL)}\rightarrow \text{Grounding}\rightarrow \text{Horn 규칙}\rightarrow \text{논리 프로그래밍}\rightarrow \text{ILP}$

스콜렘화, 일반적인 FOL 해소법, SAT 기반 학습의 세부 부호화, 메타논리의 주요 정리는 심화 내용으로 분리한다.

# 전체 개념의 연결

$\boxed{\text{FOL로 지식 표현}\rightarrow\text{Horn 규칙으로 제한}\rightarrow\text{Grounding으로 명제화}\rightarrow\text{SAT로 추론}\rightarrow\text{ILP로 규칙 학습}}$

이 과정에서 명제논리와 FOL은 지식을 표현하는 언어를 제공하고, SAT와 논리 프로그래밍은 주어진 지식에서 결론을 계산하며, ILP는 예제와 배경지식으로부터 새로운 규칙을 찾는다.

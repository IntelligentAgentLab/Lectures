# 11장. FOL의 의미론

## 1. 이 장의 목표

앞 장에서는 자연어 문장을 FOL 식으로 형식화했다.

이제 그 식이 주어진 상황에서 언제 참이고 언제 거짓인지 정의해야 한다.

명제논리에서는 명제변수에 참과 거짓을 직접 할당했다.

FOL에서는 개체, 속성, 관계, 함수, 변수, 양화사를 함께 해석해야 한다.

따라서 의미론의 기본 단위는 단순한 진리 할당이 아니라 **구조와 변수 할당**이다.

이 장을 마치면 다음을 할 수 있어야 한다.

1. FOL 구조와 해석의 역할을 설명한다.
2. 논의 영역이 의미론에서 하는 일을 설명한다.
3. 개체 상항, 술어 기호, 함수 기호의 해석을 구분한다.
4. 변수 할당과 항의 지시 대상을 계산한다.
5. 원자식과 복합식의 만족 조건을 적용한다.
6. 전칭·존재 양화사의 의미를 변수 할당의 변경으로 설명한다.
7. 열린 식과 닫힌 문장의 평가 차이를 설명한다.
8. 모델과 반모델을 구분한다.
9. 참, 만족 가능성, 타당성, 논리적 함축을 구분한다.
10. 명제논리 진리표와 FOL 모델 검사의 차이를 설명한다.

이 장의 중심 질문은 다음과 같다.

> 기호뿐인 FOL 문장이 하나의 구조 안에서 어떻게 참 또는 거짓이 되는가?

---

## 2. 구문에서 의미론으로

다음 식은 FOL의 올바르게 형성된 문장이다.

```text
∀x(Student(x) → Kind(x))
```

구문만으로는 이 문장이 참인지 알 수 없다.

다음 정보가 필요하다.

- 어떤 개체들을 대상으로 하는가?
- 그중 어떤 개체가 학생인가?
- 그중 어떤 개체가 친절한가?

이 정보를 제공하는 것이 구조다.

### 2.1 구문의 질문

> 이 기호열은 형성 규칙에 맞는가?

### 2.2 의미론의 질문

> 이 구조에서 이 문장은 참인가?

잘 형성된 문장이 언제나 참인 것은 아니다.

잘 형성됨은 문법적 성질이고, 참과 거짓은 해석에 따른 의미론적 성질이다.

---

## 3. 하나의 예시 구조

이 장에서는 다음 작은 구조를 반복해서 사용한다.

논의 영역은 세 개체로 이루어진다.

```text
D = {앨리스, 밥, 책1}
```

개체 상항은 다음처럼 해석한다.

```text
a ↦ 앨리스
b ↦ 밥
k ↦ 책1
```

단항 술어는 다음처럼 해석한다.

```text
Student = {앨리스, 밥}
Kind    = {앨리스}
Book    = {책1}
```

이항 술어는 다음처럼 해석한다.

```text
Reads = {
  (앨리스, 책1),
  (밥, 책1)
}
```

함수 기호 `fav(x)`를 `x가 가장 좋아하는 대상`으로 해석하고 다음처럼 정한다.

```text
fav(앨리스) = 책1
fav(밥)     = 책1
fav(책1)    = 책1
```

이 구조에서 다음 원자식은 참이다.

```text
Student(a)
Kind(a)
Reads(a,k)
fav(a)=k
```

다음 원자식은 거짓이다.

```text
Kind(b)
Book(a)
Reads(k,a)
```

같은 기호도 다른 구조에서는 다른 대상을 가리키고 다른 진릿값을 가질 수 있다.

---

## 4. 구조와 해석의 정식 표현

FOL 구조는 보통 다음처럼 쓴다.

```text
𝓜 = ⟨D, I⟩
```

- `D`는 논의 영역이다.
- `I`는 비논리 기호에 의미를 부여하는 해석 함수다.

어휘 또는 시그니처에 다음 기호가 있다고 하자.

```text
a, b, k
Student, Kind, Book, Reads
fav
```

해석 함수 `I`는 각 기호를 구조 안의 적절한 대상으로 보낸다.

```text
I(a) ∈ D
I(Student) ⊆ D
I(Reads) ⊆ D²
I(fav): D → D
```

문헌에서는 `I(a)` 대신 다음 표기를 자주 사용한다.

```text
a^𝓜
Student^𝓜
Reads^𝓜
fav^𝓜
```

위 첨자 `𝓜`은 해당 기호를 구조 `𝓜`에서 해석한 결과라는 뜻이다.

---

## 5. 논의 영역

논의 영역 `D`는 변수가 가리킬 수 있는 모든 개체의 집합이다.

표준적인 고전 FOL에서는 보통 다음을 가정한다.

```text
D ≠ ∅
```

즉, 논의 영역은 비어 있지 않다.

### 5.1 양화사의 범위

```text
∀x φ
```

는 `D`의 모든 개체를 대상으로 한다.

```text
∃x φ
```

는 `D`에서 조건을 만족하는 개체가 적어도 하나 있음을 요구한다.

### 5.2 영역이 달라지면 진릿값도 달라질 수 있다

```text
∀x Student(x)
```

논의 영역이 학생들만이면 참일 수 있다.

논의 영역에 책이 포함되면 거짓일 수 있다.

따라서 양화문을 평가할 때는 항상 무엇이 영역에 들어 있는지 확인해야 한다.

### 5.3 이름 없는 개체

영역의 모든 개체가 개체 상항으로 이름 붙어 있을 필요는 없다.

양화사는 이름이 없는 개체도 포함해 영역 전체를 돈다.

---

## 6. 개체 상항의 해석

각 개체 상항은 영역의 한 개체를 가리킨다.

```text
a^𝓜 = 앨리스
b^𝓜 = 밥
k^𝓜 = 책1
```

### 6.1 서로 다른 이름이 서로 다른 개체를 보장하지 않는다

표준 FOL에는 보통 유일 이름 가정이 없다.

따라서 다음이 가능하다.

```text
a^𝓜 = b^𝓜
```

기호 `a`와 `b`가 서로 달라도 같은 개체를 가리킬 수 있다.

### 6.2 모든 개체에 이름이 있을 필요도 없다

영역에 이름 없는 개체가 있을 수 있다.

따라서 양화사를 모든 상항의 유한한 나열과 항상 동일시할 수 없다.

### 6.3 상항은 구조에 의해 고정된다

한 구조가 정해지면 상항의 지시 대상은 변수 할당과 무관하다.

변수는 할당에 따라 달라지지만 상항은 구조의 해석이 정한다.

---

## 7. 술어 기호의 해석

단항 술어는 영역의 부분집합으로 해석된다.

```text
Student^𝓜 ⊆ D
```

예시 구조에서는 다음과 같다.

```text
Student^𝓜 = {앨리스, 밥}
```

따라서 `Student(a)`가 참인 이유는 다음과 같다.

```text
a^𝓜 ∈ Student^𝓜
```

### 7.1 이항 술어

이항 술어는 순서쌍의 집합으로 해석된다.

```text
Reads^𝓜 ⊆ D²
```

예시 구조에서는 다음과 같다.

```text
Reads^𝓜 = {
  (앨리스, 책1),
  (밥, 책1)
}
```

`Reads(a,k)`가 참인 이유는 다음과 같다.

```text
(a^𝓜, k^𝓜) ∈ Reads^𝓜
```

### 7.2 n항 술어

n항 술어 `P`는 `Dⁿ`의 부분집합으로 해석된다.

```text
P^𝓜 ⊆ Dⁿ
```

논항의 순서는 순서쌍 또는 순서 n-튜플의 순서로 보존된다.

---

## 8. 함수 기호의 해석

n항 함수 기호 `f`는 다음 함수로 해석된다.

```text
f^𝓜: Dⁿ → D
```

함수는 n개의 개체를 입력받아 영역 안의 한 개체를 출력한다.

### 8.1 표준 FOL의 함수는 전함수다

표준 FOL에서는 모든 가능한 입력에 대해 출력이 정의되어야 한다.

예시의 `fav`는 책1에도 값을 가져야 한다.

```text
fav^𝓜(책1) = 책1
```

일상 언어에서 가장 좋아하는 대상이 없는 개체를 허용하고 싶다면 다음 중 하나를 선택할 수 있다.

- 특별한 기본 개체를 영역에 넣는다.
- 함수를 쓰지 않고 관계로 표현한다.
- 부분함수를 허용하는 다른 논리 체계를 명시한다.

### 8.2 함수와 술어의 차이

- 함수는 개체를 반환한다.
- 술어는 어떤 튜플이 관계에 속하는지를 통해 원자식의 참과 거짓을 정한다.

```text
fav(a)
```

는 항이다.

```text
Book(fav(a))
```

는 원자식이다.

---

## 9. 동일성 기호의 해석

동일성을 포함한 표준 FOL에서 `=`는 실제 동일성으로 해석된다.

```text
𝓜,g ⊨ t₁=t₂
```

일 필요충분조건은 두 항이 같은 개체를 지시하는 것이다.

```text
⟦t₁⟧_{𝓜,g} = ⟦t₂⟧_{𝓜,g}
```

예시 구조에서는 다음이 참이다.

```text
fav(a)=k
```

두 항 모두 책1을 가리키기 때문이다.

### 9.1 기호의 모양과 지시 대상

```text
a=b
```

의 진릿값은 기호 `a`와 `b`의 철자가 같은지가 아니라 두 상항의 해석이 같은지에 달려 있다.

---

## 10. 변수 할당

변수는 구조의 해석만으로 지시 대상이 정해지지 않는다.

변수 할당 `g`가 필요하다.

```text
g: Var → D
```

예를 들어 다음과 같이 정할 수 있다.

```text
g(x) = 앨리스
g(y) = 책1
g(z) = 밥
```

### 10.1 구조와 할당의 역할

- 구조 `𝓜`은 상항, 술어, 함수의 의미를 정한다.
- 변수 할당 `g`는 자유 변수의 현재 지시 대상을 정한다.

### 10.2 열린 식의 진릿값

```text
Student(x)
```

는 `g(x)=앨리스`이면 참이고 `g(x)=책1`이면 거짓이다.

따라서 열린 식은 구조뿐 아니라 변수 할당에도 의존한다.

---

## 11. 항의 지시 대상

항의 의미는 영역 안의 한 개체다.

항 `t`의 지시 대상을 다음처럼 쓴다.

```text
⟦t⟧_{𝓜,g}
```

항의 값은 귀납적으로 계산한다.

### 11.1 변수

```text
⟦x⟧_{𝓜,g} = g(x)
```

### 11.2 개체 상항

```text
⟦a⟧_{𝓜,g} = a^𝓜
```

상항의 값은 `g`에 의존하지 않는다.

### 11.3 함수항

```text
⟦f(t₁,...,tₙ)⟧_{𝓜,g}
= f^𝓜(
    ⟦t₁⟧_{𝓜,g},
    ...,
    ⟦tₙ⟧_{𝓜,g}
  )
```

예시 구조에서 `g(x)=앨리스`라면 다음과 같다.

```text
⟦fav(x)⟧_{𝓜,g}
= fav^𝓜(앨리스)
= 책1
```

항은 참이나 거짓이 아니라 개체를 지시한다.

---

## 12. 만족 관계

식이 구조와 할당에서 참이라는 관계를 **만족 관계**라고 한다.

다음처럼 쓴다.

```text
𝓜,g ⊨ φ
```

읽는 방법은 다음과 같다.

> 구조 `𝓜`과 할당 `g`가 식 `φ`를 만족한다.

또는

> 식 `φ`는 `𝓜,g`에서 참이다.

만족하지 않음을 다음처럼 쓴다.

```text
𝓜,g ⊭ φ
```

만족 관계는 원자식에서 시작해 연결사와 양화사에 대해 재귀적으로 정의된다.

---

## 13. 원자식의 만족 조건

### 13.1 술어 원자식

```text
𝓜,g ⊨ P(t₁,...,tₙ)
```

일 필요충분조건은 항들의 값으로 만든 튜플이 `P^𝓜`에 속하는 것이다.

```text
(
  ⟦t₁⟧_{𝓜,g},
  ...,
  ⟦tₙ⟧_{𝓜,g}
) ∈ P^𝓜
```

### 13.2 예시

`g(x)=앨리스`이고 `g(y)=책1`이라 하자.

```text
𝓜,g ⊨ Reads(x,y)
```

인 이유는 다음 순서쌍이 `Reads^𝓜`에 속하기 때문이다.

```text
(앨리스, 책1)
```

### 13.3 동일성 원자식

```text
𝓜,g ⊨ t₁=t₂
```

일 필요충분조건은 두 항의 값이 같은 것이다.

---

## 14. 연결사의 만족 조건

연결사는 명제논리와 같은 진리 조건을 사용한다.

### 14.1 부정

```text
𝓜,g ⊨ ¬φ
```

일 필요충분조건은 다음이 성립하지 않는 것이다.

```text
𝓜,g ⊨ φ
```

### 14.2 논리곱

```text
𝓜,g ⊨ φ∧ψ
```

일 필요충분조건은 `φ`와 `ψ`를 모두 만족하는 것이다.

### 14.3 논리합

```text
𝓜,g ⊨ φ∨ψ
```

일 필요충분조건은 둘 중 적어도 하나를 만족하는 것이다.

### 14.4 조건문

```text
𝓜,g ⊨ φ→ψ
```

일 필요충분조건은 `φ`를 만족하지 않거나 `ψ`를 만족하는 것이다.

### 14.5 쌍조건문

```text
𝓜,g ⊨ φ↔ψ
```

일 필요충분조건은 `φ`와 `ψ`가 같은 진릿값을 갖는 것이다.

FOL 의미론에서 새로 필요한 핵심은 항, 원자식, 양화사의 평가다.

---

## 15. 변수 할당의 변경

양화사의 의미를 정의하려면 한 변수의 값만 바꾼 할당이 필요하다.

```text
g[x↦d]
```

는 다음 할당이다.

- 변수 `x`에는 개체 `d`를 할당한다.
- `x` 이외의 모든 변수에는 `g`와 같은 값을 할당한다.

정식으로 쓰면 다음과 같다.

```text
g[x↦d](x) = d
```

그리고 `z≠x`이면 다음과 같다.

```text
g[x↦d](z) = g(z)
```

양화사는 구조를 바꾸지 않는다.

같은 구조 안에서 특정 변수의 후보값을 영역 전체에 걸쳐 바꾼다.

---

## 16. 전칭 양화사의 만족 조건

```text
𝓜,g ⊨ ∀x φ
```

일 필요충분조건은 영역의 모든 개체 `d`에 대해 다음이 성립하는 것이다.

```text
𝓜,g[x↦d] ⊨ φ
```

즉, `x`의 값을 영역의 어떤 개체로 바꾸어도 `φ`가 참이어야 한다.

### 16.1 예시

```text
∀x(Student(x) → Reads(x,k))
```

예시 구조의 세 개체를 차례로 검사한다.

1. `x=앨리스`: 학생이고 책1을 읽으므로 참이다.
2. `x=밥`: 학생이고 책1을 읽으므로 참이다.
3. `x=책1`: 학생이 아니므로 조건문은 참이다.

따라서 문장 전체는 참이다.

### 16.2 전칭문의 반례

전칭문을 거짓으로 만들려면 영역에서 `φ`를 거짓으로 만드는 개체 하나면 충분하다.

---

## 17. 존재 양화사의 만족 조건

```text
𝓜,g ⊨ ∃x φ
```

일 필요충분조건은 영역의 어떤 개체 `d`가 존재하여 다음이 성립하는 것이다.

```text
𝓜,g[x↦d] ⊨ φ
```

그 개체 `d`를 존재 양화문의 **증인**이라고 부를 수 있다.

### 17.1 예시

```text
∃x(Student(x) ∧ Kind(x))
```

`x=앨리스`로 두면 두 원자식이 모두 참이다.

따라서 앨리스가 증인이며 문장 전체는 참이다.

### 17.2 거짓인 존재문

```text
∃x(Student(x) ∧ Book(x))
```

예시 구조에서 학생이면서 책인 개체는 없다.

따라서 이 문장은 거짓이다.

---

## 18. 자유 변수와 의미 의존성

열린 식의 진릿값은 자유 변수에 대한 할당에 의존한다.

```text
Student(x) ∧ Kind(x)
```

예시 구조에서 다음 두 할당을 비교하자.

```text
g₁(x)=앨리스
g₂(x)=밥
```

그러면 다음과 같다.

```text
𝓜,g₁ ⊨ Student(x) ∧ Kind(x)
```

하지만 다음은 성립하지 않는다.

```text
𝓜,g₂ ⊨ Student(x) ∧ Kind(x)
```

밥은 학생이지만 친절하지 않게 해석되어 있기 때문이다.

### 18.1 관련 없는 변수의 값

식의 자유 변수에 포함되지 않는 변수의 할당값은 진릿값에 영향을 주지 않는다.

이를 의미론의 일치 성질 또는 coincidence 성질과 연결해 설명할 수 있다.

---

## 19. 닫힌 문장은 할당과 무관하다

닫힌 문장에는 자유 변수가 없다.

```text
∃x(Student(x) ∧ Kind(x))
```

이 문장의 진릿값은 시작 할당 `g`가 무엇이든 같다.

따라서 문장에 대해서는 할당을 생략하고 다음처럼 쓴다.

```text
𝓜 ⊨ φ
```

이는 구조 `𝓜`이 문장 `φ`를 만족한다는 뜻이다.

### 19.1 양화된 변수의 이전 값

`∀xφ` 또는 `∃xφ`를 평가할 때 `g(x)`의 기존 값은 양화사 안에서 덮어쓴다.

따라서 속박된 변수의 원래 할당값은 문장 전체의 진릿값을 결정하지 않는다.

---

## 20. 예제: 구조에서 문장 평가하기

다음 문장을 평가하자.

```text
∀x(Student(x) → Kind(x))
```

예시 구조에서 학생은 앨리스와 밥이다.

- 앨리스는 친절하다.
- 밥은 친절하지 않다.

`x=밥`일 때 전건은 참이고 후건은 거짓이다.

따라서 조건문은 거짓이고 전칭문 전체도 거짓이다.

```text
𝓜 ⊭ ∀x(Student(x) → Kind(x))
```

밥은 이 전칭문에 대한 반례다.

### 20.1 존재문과 비교

```text
∃x(Student(x) ∧ Kind(x))
```

은 앨리스를 증인으로 가지므로 참이다.

같은 구조에서도 전칭문과 존재문은 다르게 평가될 수 있다.

---

## 21. 예제: 다중 양화문 평가하기

다음 문장을 평가하자.

```text
∀x(Student(x) → ∃y(Book(y) ∧ Reads(x,y)))
```

학생인 개체마다 책이면서 그 학생이 읽는 개체를 찾아야 한다.

### 21.1 앨리스

`x=앨리스`일 때 `y=책1`이 증인이다.

### 21.2 밥

`x=밥`일 때도 `y=책1`이 증인이다.

### 21.3 책1

`x=책1`일 때 전건 `Student(x)`가 거짓이므로 조건문은 참이다.

따라서 전체 문장은 참이다.

```text
𝓜 ⊨ ∀x(Student(x) → ∃y(Book(y) ∧ Reads(x,y)))
```

이 구조에서는 우연히 두 학생이 같은 책을 읽지만 식 자체는 학생마다 다른 책을 허용한다.

---

## 22. 모델

구조 `𝓜`이 문장 `φ`를 만족하면 `𝓜`을 `φ`의 모델이라고 한다.

```text
𝓜 ⊨ φ
```

문장 집합 `Γ`의 모든 문장을 `𝓜`이 만족하면 `𝓜`은 `Γ`의 모델이다.

```text
𝓜 ⊨ Γ
```

이는 다음을 뜻한다.

```text
모든 γ∈Γ에 대해 𝓜⊨γ
```

### 22.1 모델은 식이 아니라 구조다

`φ`가 모델이라고 말하지 않는다.

구조가 문장 또는 문장 집합을 만족할 때 그 구조를 모델이라고 한다.

---

## 23. 반모델

문장 `φ`를 거짓으로 만드는 구조를 `φ`의 반모델이라고 부를 수 있다.

```text
𝓜 ⊭ φ
```

논리적 함축을 반박하려면 전제들을 모두 참으로 만들면서 결론을 거짓으로 만드는 구조가 필요하다.

```text
𝓜 ⊨ Γ
```

이면서

```text
𝓜 ⊭ φ
```

인 구조 `𝓜`이 있으면 다음 함축은 성립하지 않는다.

```text
Γ ⊭ φ
```

### 23.1 작은 반모델

비타당성을 보일 때는 가능한 한 작은 영역과 단순한 해석을 먼저 시도한다.

한두 개체만으로 충분한 경우가 많다.

---

## 24. 만족 가능성과 만족 불가능성

문장 `φ`가 적어도 하나의 구조에서 참이면 만족 가능하다.

```text
어떤 𝓜에 대해 𝓜 ⊨ φ
```

문장 집합 `Γ`가 적어도 하나의 공통 모델을 가지면 만족 가능하다.

### 24.1 만족 불가능성

어떤 구조도 `φ`를 참으로 만들 수 없으면 만족 불가능하다.

예를 들어 다음 문장은 동일성을 표준적으로 해석하면 만족 불가능하다.

```text
∃x(x≠x)
```

### 24.2 한 구조에서 거짓인 것과 만족 불가능한 것은 다르다

예시 구조에서 거짓인 문장도 다른 구조에서는 참일 수 있다.

만족 불가능성은 모든 가능한 구조를 고려한 성질이다.

---

## 25. 타당성

문장 `φ`가 모든 FOL 구조에서 참이면 논리적으로 타당하다.

```text
⊨ φ
```

예를 들어 다음 문장은 타당하다.

```text
(∀x P(x)) → ∃x P(x)
```

표준 FOL에서 논의 영역이 비어 있지 않기 때문이다.

다음 문장도 타당하다.

```text
∀x(P(x) → P(x))
```

### 25.1 한 구조에서 참인 것과 타당한 것은 다르다

```text
Student(a)
```

는 예시 구조에서 참이지만 모든 구조에서 참인 것은 아니다.

따라서 타당하지 않다.

### 25.2 타당성의 반례

문장이 타당하지 않음을 보이려면 그 문장을 거짓으로 만드는 구조 하나를 제시하면 된다.

---

## 26. 논리적 함축

문장 집합 `Γ`가 문장 `φ`를 논리적으로 함축한다는 것은 다음과 같다.

```text
Γ ⊨ φ
```

이는 모든 구조 `𝓜`에 대해 다음이 성립한다는 뜻이다.

```text
𝓜 ⊨ Γ 이면 𝓜 ⊨ φ
```

즉, 전제들의 모든 모델이 결론의 모델이어야 한다.

### 26.1 예시

```text
Γ = {
  ∀x(Human(x) → Mortal(x)),
  Human(a)
}
```

그러면 다음이 성립한다.

```text
Γ ⊨ Mortal(a)
```

어떤 구조에서든 두 전제가 참이면 `a`가 인간이고 모든 인간이 죽으므로 `a`는 죽는다.

### 26.2 함축의 반박

전제들을 모두 만족하면서 결론을 만족하지 않는 반모델 하나를 찾으면 된다.

---

## 27. 논리적 동치

두 문장 `φ`와 `ψ`가 모든 구조에서 같은 진릿값을 가지면 논리적으로 동치다.

```text
φ ≡ ψ
```

또는 다음처럼 표현할 수 있다.

```text
⊨ φ↔ψ
```

예를 들어 다음 두 문장은 동치다.

```text
¬∀x P(x)
```

```text
∃x ¬P(x)
```

또한 다음 두 문장도 동치다.

```text
¬∃x P(x)
```

```text
∀x ¬P(x)
```

### 27.1 열린 식의 동치

열린 식의 동치는 모든 구조와 모든 변수 할당에서 같은 진릿값을 갖는 것으로 정의한다.

---

## 28. 참, 만족 가능, 타당을 구분한다

세 표현은 서로 다른 비교 범위를 가진다.

### 28.1 참

```text
𝓜 ⊨ φ
```

특정 구조 `𝓜`에서 참이다.

### 28.2 만족 가능

```text
어떤 𝓜에 대해 𝓜 ⊨ φ
```

적어도 하나의 구조에서 참이다.

### 28.3 타당

```text
모든 𝓜에 대해 𝓜 ⊨ φ
```

모든 구조에서 참이다.

### 28.4 포함 관계

타당한 문장은 만족 가능하다.

그러나 만족 가능한 문장이 항상 타당한 것은 아니다.

한 특정 구조에서 참이라는 사실만으로 만족 가능성은 보일 수 있지만 타당성은 보일 수 없다.

---

## 29. 명제논리의 진리표와 FOL 구조

명제논리에서는 원자명제에 참과 거짓을 부여하면 된다.

명제변수가 `n`개이면 `2ⁿ`개의 진리 할당을 조사할 수 있다.

FOL에서는 다음을 선택해야 한다.

- 논의 영역의 크기와 구성
- 각 상항의 지시 대상
- 각 술어의 외연
- 각 함수의 대응
- 열린 식을 위한 변수 할당

### 29.1 가능한 구조의 수

영역의 크기가 고정되지 않으면 가능한 구조는 무한히 많다.

영역이 고정되어도 술어와 함수의 가능한 해석이 매우 많을 수 있다.

따라서 일반적인 FOL 타당성을 유한한 진리표 하나로 판정할 수 없다.

### 29.2 유한 영역의 전개

영역이 정확히 `{d₁,...,dₙ}`이고 각 개체를 가리키는 이름이 있다고 가정하면 다음처럼 이해할 수 있다.

```text
∀x P(x)
```

는

```text
P(d₁) ∧ ... ∧ P(dₙ)
```

처럼 전개된다.

하지만 이는 영역이 유한하고 이름으로 완전히 열거된다는 추가 조건에 의존한다.

---

## 30. 의미론에서 자주 발생하는 오류

### 오류 1. 구조와 식을 혼동한다

식은 모델이 아니다.

구조가 식을 만족할 때 그 구조가 모델이다.

### 오류 2. 술어를 참·거짓 하나로 해석한다

단항 술어는 영역의 부분집합이고 n항 술어는 `Dⁿ`의 부분집합이다.

원자식은 항의 값이 그 외연에 속하는지에 따라 참 또는 거짓이 된다.

### 오류 3. 함수와 관계를 혼동한다

함수는 각 입력에 영역의 개체 하나를 반환한다.

관계는 허용되는 튜플들의 집합이다.

### 오류 4. 상항과 변수를 같은 방식으로 평가한다

상항은 구조의 해석이 정하고 변수는 할당이 정한다.

### 오류 5. 양화사가 구조를 바꾼다고 생각한다

양화사는 같은 구조 안에서 변수 할당의 한 값만 바꾼다.

### 오류 6. 전칭문을 이름이 있는 개체만 검사한다

양화사는 이름이 없는 개체까지 포함해 영역 전체를 돈다.

### 오류 7. 한 구조에서 참이면 타당하다고 생각한다

타당성은 모든 구조에서의 참을 요구한다.

### 오류 8. 만족 가능성과 타당성을 혼동한다

만족 가능성은 모델 하나면 충분하지만 타당성은 반모델이 하나도 없어야 한다.

### 오류 9. 열린 식의 할당을 생략한다

자유 변수가 있는 식은 일반적으로 `𝓜,g`에서 평가해야 한다.

### 오류 10. 서로 다른 상항은 서로 다른 개체라고 가정한다

유일 이름 가정을 별도로 두지 않으면 두 상항은 같은 개체를 가리킬 수 있다.

---

## 31. 의미론 판정 절차

주어진 구조에서 식을 평가할 때 다음 순서를 사용한다.

### 31.1 1단계: 구조를 표로 정리한다

- 논의 영역
- 상항의 지시 대상
- 술어의 외연
- 함수의 대응

### 31.2 2단계: 자유 변수를 찾는다

자유 변수가 있으면 필요한 변수 할당을 확인한다.

### 31.3 3단계: 항의 값을 계산한다

변수, 상항, 함수항의 값을 안쪽부터 계산한다.

### 31.4 4단계: 원자식을 평가한다

튜플이 술어의 외연에 들어 있는지 또는 두 항의 값이 같은지 확인한다.

### 31.5 5단계: 연결사를 평가한다

작은 부분식부터 진리 조건을 적용한다.

### 31.6 6단계: 양화사를 평가한다

- 전칭은 모든 후보를 확인한다.
- 존재는 증인 하나를 찾는다.

### 31.7 7단계: 판정 범위를 말한다

결론이 특정 구조에서의 참인지, 만족 가능성인지, 타당성인지 구분해 말한다.

---

## 32. 수업 활동

### 활동 1. 구조를 그리기

영역 `D={a,b,c}`를 세 점으로 그린다.

단항 술어 `P`에 속하는 점을 색칠하고 이항 술어 `R`에 속하는 순서쌍을 화살표로 표시한다.

다음 원자식의 진릿값을 판정한다.

```text
P(a)
R(a,b)
R(b,a)
```

### 활동 2. 할당 바꾸기

같은 구조에서 `P(x)`를 평가한다.

`g(x)=a`, `g(x)=b`, `g(x)=c`일 때의 결과를 비교한다.

### 활동 3. 전칭문의 반례 찾기

```text
∀x(P(x) → Q(x))
```

을 거짓으로 만드는 개체가 어떤 조건을 가져야 하는지 말한다.

정답은 `P`에는 속하지만 `Q`에는 속하지 않는 개체다.

### 활동 4. 존재문의 증인 찾기

```text
∃x(P(x) ∧ R(x,a))
```

을 참으로 만드는 증인을 구조 그림에서 찾는다.

### 활동 5. 작은 반모델 만들기

다음 함축이 성립하지 않음을 보이는 구조를 만든다.

```text
∃x P(x) ⊨ ∀x P(x)
```

두 개체 중 하나만 `P`에 속하게 하면 된다.

## 33. 연습문제

다음 구조를 사용한다.

```text
D = {u, v, w}
a^𝓜 = u
b^𝓜 = v
P^𝓜 = {u, v}
Q^𝓜 = {v}
R^𝓜 = {(u,v), (v,v), (w,u)}
f^𝓜(u)=v
f^𝓜(v)=v
f^𝓜(w)=u
```

변수 할당은 다음과 같다.

```text
g(x)=u
g(y)=w
```

### 문제 1

## 35. 60분 수업 운영안

### 0–8분: 구조가 필요한 이유

- 같은 FOL 문장이 구조에 따라 참 또는 거짓이 됨을 보인다.
- 구문과 의미론을 구분한다.

### 8–20분: 구조의 구성요소

- 논의 영역, 상항, 술어, 함수의 해석을 소개한다.
- 하나의 작은 구조를 표로 정리한다.

### 20–30분: 항과 원자식

- 변수 할당을 소개한다.
- 항의 값을 재귀적으로 계산한다.
- 술어 외연과 동일성으로 원자식을 평가한다.

### 30–42분: 양화사

- `g[x↦d]`를 사용해 전칭과 존재의 만족 조건을 정의한다.
- 반례와 증인을 구조에서 찾는다.

### 42–50분: 모델과 반모델

- 한 문장과 문장 집합의 모델을 구분한다.
- 논리적 함축을 반박하는 반모델을 만든다.

### 50–57분: 의미론적 성질

- 참, 만족 가능, 타당, 함축, 동치를 구분한다.
- 명제논리 진리표와 FOL 구조를 비교한다.

### 57–60분: 형성평가

- 주어진 작은 구조에서 전칭문 하나와 존재문 하나를 평가한다.

## 37. 핵심 정리

1. FOL 문장의 진릿값은 구조가 제공하는 해석에 따라 달라진다.
2. 구조 `𝓜=⟨D,I⟩`는 논의 영역과 비논리 기호의 해석으로 이루어진다.
3. 표준 FOL의 논의 영역은 보통 비어 있지 않다.
4. 개체 상항은 영역의 한 개체를 가리킨다.
5. 서로 다른 상항이 같은 개체를 가리킬 수 있다.
6. n항 술어는 `Dⁿ`의 부분집합으로 해석된다.
7. n항 함수는 `Dⁿ`에서 `D`로 가는 전함수로 해석된다.
8. 변수 할당은 각 변수에 영역의 개체를 지정한다.
9. 항은 구조와 할당에서 영역의 개체 하나를 지시한다.
10. 원자식의 진릿값은 항의 값과 술어의 외연 또는 동일성으로 정한다.
11. `∀xφ`는 모든 `d∈D`에 대해 `g[x↦d]`가 `φ`를 만족해야 한다.
12. `∃xφ`는 어떤 `d∈D`에 대해 `g[x↦d]`가 `φ`를 만족하면 된다.
13. 열린 식은 자유 변수의 할당에 의존한다.
14. 닫힌 문장은 시작 변수 할당에 의존하지 않는다.
15. 구조가 문장을 만족하면 그 구조는 문장의 모델이다.
16. 만족 가능성은 어떤 모델의 존재이고 타당성은 모든 구조에서의 참이다.
17. `Γ⊨φ`는 `Γ`의 모든 모델이 `φ`의 모델이라는 뜻이다.
18. 함축을 반박하려면 전제는 참이고 결론은 거짓인 반모델 하나면 된다.
19. FOL은 가능한 구조가 무한히 많아 일반적인 유한 진리표로 타당성을 판정할 수 없다.
